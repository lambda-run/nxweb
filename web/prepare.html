Open a game

Drop a .nup file or a game folder here

Everything stays on this computer: nothing is uploaded. nxweb opens games you own that are already unpacked. It has no keys and does not decrypt game packages.

What can I open?
A .nup file: one file that holds an unpacked game (the base game, its updates and add-ons). The newest update in it is started.
A game folder: base/exefs/ (main, main.npdm, sdk, subsdk*) and base/romfs/; optionally updates/<version>/exefs and romfs (the newest is used) and dlc/<title id>/<n>/romfs. exefs/ and romfs/ directly in the folder work too.
Not yet: .nsp, .xci, .nsz and .xcz packages. Convert them to a .nup or a folder with the tool you dumped them with.
